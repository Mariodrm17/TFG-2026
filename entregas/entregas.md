7. Metodología 
Para la realización de este proyecto se utilizará una metodología de desarrollo 
iterativo e incremental. Esta aproximación permite gestionar las dudas generadas 
por el sistema heredado y facilitar la validación con el tutor. 
A continuación, se detallan los métodos y materiales para cada objetivo 
específico: 
Metodología para el Objetivo Específico 1 (Requisitos y Análisis) 
Se aplicarán técnicas de ingeniería inversa para comprender el funcionamiento 
del sistema actual, dado que es una herramienta con la que no se tiene 
familiaridad previa. 
●​ Métodos: 
○​ Entrevistas: Reuniones periódicas con el tutor de la empresa y los 
operarios del almacén para levantar los requerimientos funcionales 
(qué debe hacer la web) y no funcionales (seguridad, rendimiento). 
○​ Análisis Documental: Revisión de informes y exportaciones de 
datos del software actual para entender la estructura de la 
información a migrar.

●​ Materiales: Herramientas de ofimática para la documentación, grabadora 
de voz (para entrevistas) y software de diagramado UML (como StarUML o 
Lucidchart) para los Casos de Uso. 
Metodología para el Objetivo Específico 2 (Diseño) 
Se procederá al diseño lógico y físico de la solución antes de iniciar la 
codificación, asegurando una base sólida para la migración. 
●​ Métodos: 
○​ Modelado de Datos: Creación del modelo Entidad-Relación 
normalizado para la nueva base de datos MySQL, eliminando 
redundancias detectadas en el sistema anterior. 
○​ Prototipado (Wireframing): Diseño de bocetos de la interfaz web 
para validar la usabilidad con el usuario final antes de programar. 
●​ Materiales: MySQL Workbench para el diseño del esquema de la base de 
datos, y herramientas de prototipado como Figma o Balsamiq para las 
interfaces web. 
Metodología para el Objetivo Específico 3 (Desarrollo y Despliegue) 
Esta fase constituye el núcleo técnico del proyecto, abarcando la construcción del 
software y la migración de datos. 
●​ Métodos: 
○​ Patrón de Diseño MVC: Se utilizará la arquitectura 
Modelo-Vista-Controlador para separar la lógica de negocio de la 
interfaz de usuario. 
○​ Proceso ETL (Extract, Transform, Load): Desarrollo de scripts 
específicos para extraer los datos del sistema antiguo, 
transformarlos al nuevo formato y cargarlos en MySQL. 
●​ Materiales: 
○​ IDE: Visual Studio Code / IntelliJ / NetBeans.

Se realizarán pruebas exhaustivas para garantizar que la migración ha sido 
exitosa y que el nuevo sistema es fiable. 
●​ Métodos: 
○​ Pruebas de Caja Negra: Validación de las funcionalidades de la 
web (login, altas, bajas de almacén) sin inspeccionar el código 
interno. 
○​ Validación de Datos (Data Consistency): Comparación cruzada 
(Cross-check) entre un reporte de stock del sistema antiguo y el 
nuevo sistema web para certificar que no hubo pérdida de datos 
durante la migración. 
●​ Materiales: Navegadores web (Chrome, Firefox) para pruebas de 
compatibilidad, y hojas de cálculo para el cotejo de datos migrados. 
 
 
8. Resumen del trabajo: 
El presente Trabajo de Fin de Grado aborda el diseño, desarrollo e 
implementación de un sistema de gestión de almacenamiento basado en entorno 
web, con el objetivo principal de modernizar la infraestructura tecnológica de la 
empresa colaboradora y migrar la totalidad de su información histórica desde un 
sistema heredado ("legacy"). Para la consecución de los objetivos, se aplicará una 
metodología de desarrollo de software iterativa e incremental, comenzando con el 
análisis de ingeniería inversa del software actual para definir los requisitos de 
migración y continuando con el diseño de un modelo de datos relacional
