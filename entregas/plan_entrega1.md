# Plan para la Entrega 1: Capítulo 1 (Capítulo Metodológico)

Basado en las directrices oficiales del TFG y en las recomendaciones del "repo Masias" (Capítulo 1), aquí tienes el plan estructurado de lo que debes redactar para tu próxima entrega.

## 🎯 Objetivo de la Entrega
Elaborar el **Capítulo 1**, que sirve como base del proyecto y puerta de entrada para comprender los objetivos, la relevancia y la metodología de tu TFG. Recuerda que debes usar la **plantilla oficial del TFG en formato Word**.

---

## 🏗️ Estructura del Capítulo 1

Debes dividir el capítulo en los siguientes apartados principales (no más de 3 niveles jerárquicos):

### 1. Introducción, Situación de Partida y Contexto (Escenario / Necesidad / Problema)
Aquí debes contextualizar la realidad y explicar el problema.
* **Etapa 1 (Contextualización):** Describe el almacén de la empresa, cómo funciona actualmente y qué características tiene.
* **Etapa 4 (Propuesta):** Introduce el problema actual (el sistema heredado/antiguo) y la necesidad de migrar la información a una base de datos **MySQL** con una **interfaz web** que permita el acceso concurrente y la gestión eficiente de la mercancía.

### 2. Estado del Arte (Perspectiva Teórica / Marco Teórico)
* **Etapa 2 (Exploración):** Investiga y menciona las soluciones o software de gestión de almacén que ya existen (ERP, sistemas de gestión logística, etc.). Puedes apoyarte en las referencias bibliográficas que pusiste en el documento D0 (Wareventory, automatización con Schneider, etc.).
* **Etapa 3 (Justificación):** Explica por qué esas soluciones existentes no son suficientes o adecuadas para esta empresa en particular y por qué es necesario tu desarrollo web *ad-hoc*.

### 3. Objetivos
Deben ser coherentes con lo planteado en el D1.
* **Objetivo General:** Implementar un sistema web de organización y almacenamiento de mercancías, incluyendo la migración de datos del sistema antiguo.
* **Objetivos Específicos:** (Mapeados con los futuros capítulos de tu TFG)
    1. Analizar los procesos logísticos y extraer los requisitos del sistema actual (Esto será el **Capítulo 2**).
    2. Diseñar la arquitectura web y el modelo entidad-relación optimizado en MySQL (Esto será el **Capítulo 3**).
    3. Implementar la aplicación web y los scripts de migración (Esto será el **Capítulo 4**).
    4. (*Opcional pero recomendado*) Verificar el sistema para que no haya pérdida de datos en la migración.

### 4. Metodología y Tareas
Define cómo vas a trabajar para conseguir los objetivos.
* **Ciclo de vida:** Menciona que usarás una metodología de desarrollo **iterativo e incremental**.
* Explica brevemente las técnicas que vas a usar (ej: reuniones periódicas para extracción de requisitos, ingeniería inversa del sistema actual, etc.).
